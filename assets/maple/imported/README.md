# Maple Junction — redistributable third-party model provenance

This folder is generated by `scripts/import_maple_cc0_assets.py`. The script
downloads the EXACT pinned revision of the following original third-party
models, verifies their original Git blob SHA, validates the actual GLB
geometry, and records each downloaded file in `catalog.json`.

## Kenney — City Kit Suburban 2.0
- Creator: Kenney, https://kenney.nl/assets/city-kit-suburban
- License: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/
- Download mirror: https://github.com/petroulacl/fps-buildings-env-kit
- Imported models: building-type-a/b/c/f/j/t and palette texture.

## Quaternius — Downtown City MegaKit and Stylized Nature assets
- Creator: Quaternius, https://quaternius.com/
- Downtown City MegaKit: https://quaternius.com/packs/downtowncitymegakit.html
- License: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/
- Download mirror: https://github.com/anshaneja5/skyline-run
- Imported models: b_small, tree1, tree3 and bush.

These files can be bundled, modified, and redistributed as part of the game.
Credits are supplied even though CC0 does not require attribution. The
original custom Maple Junction models remain separately authored in
`assets/maple/glb`.

## Kenney — Starter Kit Racing (red RC truck)
- Creator: Kenney, https://github.com/KenneyNL/Starter-Kit-Racing
- Asset: `models/vehicle-truck-red.glb` and its `models/Textures/colormap.png`
- License: CC0 1.0 Universal (the upstream README explicitly grants CC0 for 3D models).
- Source version is pinned by SHA and both model and palette are checksum-verified.
- The truck is the playable vehicle. The Cherry Coupe remains a parked custom model.
