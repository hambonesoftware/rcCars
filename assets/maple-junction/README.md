# Maple Junction · authored 3D meshes

Real, original binary **glTF 2.0** meshes for Garage Gauntlet's 20 × 10 HO-scale model railway town, generated by [generate_maple_assets.py](./generate_maple_assets.py). The generated GLBs include physically based materials and require **no network-hosted textures**.

| GLB | Approx. triangles | Game-unit size | Usage |
| --- | ---: | --- | --- |
| `glb/maple_craftsman_house.glb` | 58,772 | 13.1 × 12.0 × 13.3 | Detailed home, porch, shingles and recessed glazing |
| `glb/maple_mainstreet_hardware.glb` | 51,174 | 14.3 × 13.9 × 13.7 | Two-story Main Street brick shop and enamel signage |
| `glb/maple_cherry_coupe.glb` | 10,928 | 3.0 × 2.1 × 4.7 | Curved retro diecast-like car with wheels and glass |
| `glb/maple_scenic_tree.glb` | 18,734 | 5.2 × 7.4 × 4.2 | Authored deciduous tree with foliage clusters |

Coordinates: Y-up; ground at Y≈0; +Z faces the front of the car and buildings. One game unit is a layout design unit, not a literal foot.

This pack is a **first authored-mesh quality pass**, not a Blender sculpt or a photogrammetric scan. Meshes are intended for importing directly into PlayCanvas, not replacing its rendering engine.

## Build and validate

```bash
python -m pip install "trimesh>=4,<5" "numpy>=1.26,<3" "pillow>=10,<13"
python assets/maple-junction/generate_maple_assets.py
```

Generated binaries are stored in `glb/`. CI regenerates and validates all four, then performs live PlayCanvas WebGL rendering tests. Each file must be a valid standalone GLB.

## Inspect

Open [the asset gallery](../../maple-asset-gallery.html) through GitHub Pages. It shows the actual rendered GLB files, not screenshots. You can drag to rotate and switch models on iPhone.

## Rights

All geometry and PBR color assignments were authored for Garage Gauntlet; no third-party model assets were embedded. A system font was used for a generated sign image; no font file is distributed.
